# Sports-Card-Builder

A minimal Gemini-powered baseball card builder app that keeps a consistent Diamond Kings 1/1 identity while using player-specific palettes.

## Setup

```bash
npm install
```

## Run

```bash
GEMINI_API_KEY=your_key_here npm start
```

If `GEMINI_API_KEY` is not set, the app still returns a template-safe draft card using the locked style rules.

Open `http://localhost:3000`.

## Test

```bash
npm test
```
